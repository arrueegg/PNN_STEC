# PNN_STEC

This repository contains code and resources related to the **PNN_STEC** project.

## Overview

The project focuses on STEC modelling with Baysian Neural Networks (BNN).

## Repository Structure

- `src/` - Source code for the project.
- `config/` - Configuration files for setting up experiments and model parameters.

## Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/yourusername/PNN_STEC.git
    ```
2. Install dependencies:
    ```bash
    pip install -r requirements.txt
    ```
